# LEXA — AI Vocabulary

## Рабочее название

**LEXA — AI Vocabulary**

Слоган:

> **Не просто словарь. Личная память для иностранных слов.**

---

# Описание продукта

LEXA — это AI-словарь нового поколения.

В отличие от обычных словарей, LEXA не просто хранит перевод слова.

Он автоматически создает полноценную карточку, помогает понять значение, организует интервальное повторение и постепенно доводит слово до долговременной памяти.

Главная идея проекта — пользователь занимается не заполнением словаря, а изучением языка.

AI берет на себя всю рутинную работу.

---

# Цель проекта

Создать минималистичный сервис для изучения иностранных слов.

Пользователь должен иметь возможность:

- быстро сохранять новые слова;
- группировать слова по источникам;
- получать автоматически заполненные карточки;
- повторять слова по современному алгоритму;
- использовать AI для объяснения и изучения слов.

---

# Концепция

В центре системы находится AI.

Словарь является памятью пользователя.

Каждое добавленное слово становится частью персональной базы знаний.

AI использует эту базу для обучения пользователя.

# Добавление слов

Основной сценарий работы.

Пользователь создает новый набор.

Например:

```
📚 Ведьмак
```

После открытия набора отображается большое поле ввода.

Пользователь может вставить сразу список слов.

Например:

```
destiny
curse
monster
forest
wolf
magic
```

После нажатия "Обработать"

AI автоматически:

- удаляет пустые строки;
- удаляет дубликаты;
- определяет язык;
- ищет существующие записи;
- создает новые карточки.

---

# AI Pipeline

После получения нового слова AI выполняет следующие действия.

1. Определяет язык.
2. Определяет часть речи.
3. Находит перевод.
4. Генерирует примеры использования.
5. Генерирует синонимы.
6. Генерирует антонимы.
7. Генерирует краткое объяснение значения.
8. Определяет примерный уровень сложности.
9. Сохраняет результат.

# Карточка слова

Каждая карточка содержит.

Обязательные поля.

- оригинальное слово;
- язык;
- перевод;
- часть речи;
- пример использования;
- синонимы;
- антонимы;
- краткое объяснение;
- уровень сложности;
- дата создания.

Служебные поля.

- дата последнего повторения;
- дата следующего повторения;
- история повторений;
- статус изучения.

---

# Изучение

Каждый день пользователь получает список слов.

Во время повторения отображается только слово.

После попытки вспомнить показываются:

- перевод;
- объяснение;
- пример;
- синонимы.

После этого пользователь оценивает знание:

- Не помню
- Трудно
- Хорошо
- Легко

Оценка передается алгоритму FSRS.

# Почему проект отличается от существующих решений

Большинство словарей требуют от пользователя самостоятельно заполнять карточки и управлять процессом обучения.

LEXA делает это автоматически.

Пользователь лишь сохраняет новые слова в тематические наборы, а AI берет на себя создание качественных карточек, объяснение значений, организацию повторений и сопровождение обучения.

Таким образом сервис становится не просто хранилищем слов, а персональной системой изучения языка с долговременной памятью.
